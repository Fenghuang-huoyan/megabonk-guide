A tome is a stat you keep for the rest of that run. The offer’s rarity changes the size of the jump. The numbers below are the common-rank bonus both the wiki and the megabonk.org table print. Higher rarities give more. Do not add these up as a promise of your next level-up.

<Callout kind="note" title="Why 23, not 26">
The wiki’s tome index and megabonk.org both say 23. Fextralife has displayed 26. This page follows the two lists that name the same 23. If a patch added another, it will show up in the Unlocks menu first.
</Callout>

## Already in the pool

| Tome | Common bonus per level | Use it when |
| --- | --- | --- |
| Agility | +15% movement speed | You are getting cornered |
| Cooldown | +7.5% attack speed | The weapon should simply hit more often |
| Damage | +0.08× damage | Almost every offensive run |
| Evasion | +10% evasion | A dodge build, with the note that real returns may diminish |
| Golden | +12% gold gain | You are buying chests this run |
| Health | +25 max HP | You need a larger mistake budget |
| Knockback | +20% knockback | You want space, and the weapon actually knocks back |
| Precision | +7% crit chance | Crit characters. Over 100% is described as Overcrit |
| Projectile Speed | +15% projectile speed | Arrows, fireballs, thrown weapons |
| Regen | +40 HP regen | The wiki says per minute |
| Shield | +25 shield | A buffer that community pages describe as recharging after you stop taking hits |
| Silver | +12% Silver gain | You care about the next run’s unlocks more than this boss |
| Size | +10% size | Swings, projectiles, and areas should cover more ground |

## Unlock first

| Tome | Common bonus per level | How the indexes say you unlock it |
| --- | --- | --- |
| Armor | +12% armor | Kill 5,000 enemies as Sir Oofie |
| Attraction | +75% pickup range | Use the Shrine of Succ 8 times |
| Bloody | +10% lifesteal | Kill 12,500 enemies. The wiki describes the heal as a chance for 1 HP per hit, not a percent of damage |
| Chaos | One random stat | Charge every Charge Shrine on all three stages of a Tier 3 run without leaving the zone |
| Cursed | +3.5% difficulty | Beat a stage boss in under 5 minutes |
| Duration | +15% duration | Get the Axe to level 10 in one run |
| Luck | +7% luck | A very rare enemy drop. The wiki prints 0.01% |
| Quantity | +1 projectile | Fire 5,000 projectiles. Does not affect every weapon |
| Thorns | +15 thorns | Block 250 attacks with Aegis |
| XP | +7% XP gain | megabonk.org says break 20 pots in one run. Confirm that line in the menu |

## Picking during a level-up

- Damage, Cooldown, and Size are the boring offers that keep a starter weapon alive. Take boring while the run is fragile.
- Luck and XP pay off if the run will be long. They do not kill the boss that is already on the screen.
- Cursed Tome is a choice to make the game harder for more density. Sir Chadwell already adds difficulty. Stacking both is a later-tier decision, not a first clear.
- Bloody Tome is also the key for Blood Magic, and Thorns Tome is part of Athena’s unlock story. Some “tome levels” are quests, not just stats.
- Silver Gain was a Charge Shrine reward in older notes. A shrine guide says v1.0.49 removed it from that reward pool. Do not plan a shrine route around Silver Gain until you see it offered.
